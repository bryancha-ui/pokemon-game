# Third-party 3D map assets

## KayKit City Builder Bits 1.0

- Source: https://github.com/KayKit-Game-Assets/KayKit-City-Builder-Bits-1.0
- License: CC0 1.0 Universal (public domain dedication)
- Local files: `kaykit-city/building_A` through `building_H`, shared texture,
  and the original `LICENSE.txt`
- Use in this project: generic buildings for detected city and town plots

The source pack states that personal, educational, and commercial use is
permitted and attribution is not required. Its original license is kept beside
the vendored assets for provenance. No Nintendo or Pokémon game assets are
included in this directory.

## Kenney Nature Kit 2.1

- Source: https://kenney.nl/assets/nature-kit
- License: CC0 1.0 Universal (public domain dedication)
- Local files: three tree variants, two rock variants, their material files,
  and the original `License.txt`
- Use in this project: a performance-bounded selection blended into procedural
  forest and rocky terrain placement

The full source pack contains 330 assets. Only the five models used by the game
are vendored here to keep the web build small.

## User-provided interior models

- `interiors/pokemon_center_scene.glb`
- `interiors/pokemart.glb`

These files were supplied directly for this project and are used as visual room
shells. Phaser remains authoritative for navigation, collision, NPC interaction,
healing, shopping, and scene exits. No license metadata was included with the
files; redistribution rights should be verified before a public release.

## Remote Sketchfab embed

- Model: Celadon City
- Creator: bhavesh chalke
- Page: https://sketchfab.com/3d-models/celadon-city-6e303b91dfd643e8ad4413fb3c034ea5
- Use in this project: opt-in official Sketchfab viewer in Forest City

The Celadon mesh and textures are not downloaded or redistributed by this
project. The official remote embed is shown with a direct model and creator
credit because the public model page does not advertise a downloadable file or
reuse license.
