# Northern Region — Suno Music Prompts

Suno **Style-of-Music** prompts for every Northern-region map that currently **borrows another map's track** instead of having its own theme. Each entry lists the scene, the placeholder track it reuses today, a **reference song from an official Pokémon game** to guide the melody/mood, and a ready-to-paste Suno prompt.

**How to use in Suno**
- Paste the *Style prompt* into the **Style of Music** box.
- Turn **Instrumental ON** (game BGM has no vocals).
- Use the **Reference (Pokémon)** track as your mental target for melody, tempo and instrumentation — hum/whistle it to check your generation lands in the same emotional space. (Don't paste the copyrighted title into Suno; the descriptors carry the vibe.)
- Aim for **loopable** results: keep intro/outro minimal so the piece can repeat seamlessly.

Throughout, the game is a **Korean-set Pokémon fangame**, so prompts blend Pokémon's melodic chiptune/orchestral style with **Korean traditional instruments** (gayageum, geomungo, daegeum, piri, haegeum, janggu, buk) for regional color.

### Notes & options
- **Field-route family (1–5):** they currently all share `northroute`. The five prompts above deliberately diverge (valley / pass / coast / highlands / plateau) so each map reads distinct — but you could also compose **one** stronger `northroute` replacement and keep the rest borrowing it.
- **Villain HQ (10–11):** the road and the interior share `headquarternorth`. If you'd rather keep one HQ theme, use prompt **#11** for both and drop **#10**.
- **Rangrim/Onseong set (13–17):** designed as a mini-suite (same key/instrument palette, escalating intensity foothills → cavern → snowfield → altar → summit) so they feel like one mountain even as separate loops.
- After generating, drop the exported files into `phaser-game/public/assets/bgm/` as `bgm_<name>.mp3`, add the key to the track map in `src/systems/Music.ts`, and point each scene's `bgm`/`playBgm(...)` at the new key.
