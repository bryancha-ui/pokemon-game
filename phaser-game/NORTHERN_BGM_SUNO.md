# Northern Onnuri — BGM Suno Prompts & Reference Tracks

Theme-music scripts for every **northern-region** city, town, route and special map.
For each map you get:

- **Suno style** — paste this into Suno's *Style of Music* box (keep **[Instrumental]** in the lyrics box).
- **Suno title** — a suggested track title.
- **Reference** — an actual Pokémon track with the same feel, to guide the arrangement.
- **File key** — the `Music.ts` `TRACKS` key / suggested `bgm_*.mp3` filename.

General north palette: cold air, wide space, Korean court instruments (gayageum, daegeum,
piri, janggu) fused with modern textures. Slightly more austere and grand than the south.

## How to use
1. In Suno, put **[Instrumental]** in the lyrics box and the **Suno style** line in the *Style of Music* box.
2. Generate 2–3 takes; pick the one whose first 8 seconds loop cleanly (game themes loop).
3. Trim to a clean loop, export MP3, name it with the **File key** (`bgm_<key>.mp3`), drop it in `public/assets/bgm/`, and add the key to `TRACKS` in `src/systems/Music.ts`.
4. Call `playBgm(this, '<key>')` in that scene's `create()`.
