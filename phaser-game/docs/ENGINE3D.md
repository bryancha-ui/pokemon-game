# engine3d — 3D 렌더링 레이어

Phaser 게임 로직(입력·충돌·인카운터·대사·저장·음악)은 **한 줄도 바뀌지 않았습니다.**
`src/engine3d/`가 실행 중인 씬을 관찰해 3D 트윈을 Phaser 캔버스 아래에 렌더링하고,
Phaser는 투명 캔버스로 UI를 그 위에 계속 그립니다.

## 조작

- **F3** — 언제든 2D ↔ 3D 전환 (localStorage `pk3d.enabled`에 저장, 기본 3D)

## 씬별 동작

| 씬 | 처리 |
|---|---|
| 오버월드 (카메라 팔로우) | 맵 그림을 3D 바닥에 투영 + 타일 색 분류로 나무·풀·꽃·바위·절벽·물 생성, 3인칭 추적 카메라 |
| 실내 (`playerG` 보유, 고정 카메라) | 방 콘텐츠 기준으로 월드 산정, 디오라마 카메라, 실내 조명 |
| 배틀 (`*Battle*` 키) | 3D 아레나 + 크리처 입체 모델, 시네마틱 카메라(드리프트·펀치인·셰이크). 기존 배틀 트윈이 그대로 3D 연출을 구동 |
| 타이틀/메뉴/도감 등 | 의도적으로 2D 유지 |

## 구조 (`src/engine3d/`)

- `index.ts` — 부트스트랩, 씬 선택, F3 토글
- `GraphicsRaster.ts` — Phaser Graphics 커맨드 버퍼 → 캔버스 래스터라이저
- `Extruder.ts` — 2D 아트 → 입체 릴리프 메시(앞뒤 텍스처 + 측면 평균색 조각면)
- `TerrainBuilder.ts` — 바닥 투영 + 타일 색 분류 → 지형/소품 생성
- `Props.ts` — 나무·소나무·바위·풀·꽃·물·벽 절차 모델(툰 셰이딩)
- `ThreeStage.ts` — 렌더러·조명·하늘·환경 프리셋(day/snow/cave/interior/battle)
- `OverworldMirror.ts` / `BattleMirror.ts` — 씬 상태 → 3D 동기화(매 프레임)
- `CameraRig.ts` — 3인칭·실내·배틀 카메라
- `GlbModels.ts` — 생성형 3D 모델(GLB) 자동 적용 훅

## 배틀 3D 모션 (`CreatureAnimator.ts`)

3D 모델이 기술을 **직접 연기**합니다. 기술 데이터(카테고리·타입·위력)는 게임이 이미 PokeAPI에서 가져오는 값을 그대로 사용하며, 배틀 로직은 변경되지 않았습니다.

- **물리 기술** — 웅크림(스쿼시) → 전방 돌진(아크 점프) → 복귀. 위력이 높을수록 크게 움직임(PokeAPI `power` 기준)
- **특수 기술** — 뒤로 젖히며 차징 → 발사 반동. 타입 색상 오브가 포물선으로 날아가 충격파+파편으로 폭발
- **변화 기술** — 제자리 도약 + 회전 플로리시, 사용자 주변 오라 펄스
- **피격/기절** — 반동 리코일 + 흔들림, 기절 시 쓰러지는 모션
- **리깅 GLB 지원** — 모델에 애니메이션 클립이 있으면 `AnimationMixer`로 재생하고 이름(idle/attack/hit/faint)으로 자동 매칭. 스킨드 메시는 `SkeletonUtils`로 복제해 개체별 독립 재생

## 추가 기능

- **3D 주인공** — `CharacterModel.ts`의 파라메트릭 휴머노이드(성별별 교복 디자인)가 릴리프 대신 표시되고, 걷기 사이클(팔다리 스윙·바운스)과 4방향 회전을 이동에서 자동 구동. 자전거 포즈(가로로 넓은 아트)일 땐 릴리프로 자동 폴백.
- **3D 기술 이펙트** — `MoveFX3D.ts`. 특수기는 타입 색상의 발광 오브가 포물선으로 날아가고, 임팩트에 충격파 링+파편 분출+카메라 펀치인/셰이크. 물리기는 (미러가 이미 재현하는) 돌진에 맞춰 임팩트 버스트. `BattleFX.ts`의 시각 전용 이벤트 한 줄로 구동되며 로직 무변경.
- **볼륨 빌딩** — 도시 맵에 그려진 건물 풋프린트(창문 격자 등 고분산 영역)를 자동 감지해 파사드 벽+처마+지붕(원화 풋프린트 유지)으로 압출. `assets/textures3d/facade.png`·`roof.png`를 넣으면 모든 빌딩에 자동 적용(없으면 절차 생성 파사드).

## 생성형 3D 모델 연동 (힉스필드 등)

1. GLB 파일을 `public/assets/models3d/<크리처키>.glb`로 저장 (예: `vipour.glb`)
2. `public/assets/models3d/manifest.json` 작성:

   ```json
   { "models": ["vipour"] }
   ```

3. 끝. 배틀에서 해당 크리처는 릴리프 대신 진짜 3D 모델로 자동 표시됩니다.
   (manifest가 없으면 기능은 조용히 꺼진 상태)
